# 🦠 COVID-19 Interactive Dashboard

This project is an interactive data dashboard built in Jupyter Notebook using:

- **Pandas** for data handling
- **Plotly** for interactive visualizations
- **ipywidgets** for dynamic controls

It uses real-world COVID-19 data from [Our World in Data](https://ourworldindata.org/covid-cases) and allows users to:

✅ Select a country from a dropdown  
✅ View time-series plots of total confirmed COVID-19 cases  
✅ Explore trends with interactive plots

---

## 🚀 How to Run

1. Clone the repository or download the `.ipynb` file.
2. Open it in Jupyter Notebook or JupyterLab.
3. Run each cell step-by-step.
4. Use the dropdown to select different countries.
